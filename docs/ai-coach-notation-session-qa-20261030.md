# Coach: chess speech and return from analysis, 2026-10-30

The owner reports successful authenticated text replies, public game selection and natural read-aloud on the existing isolated QA. This is owner acceptance of the previous version, not an independent live-provider test by this runner.

## Changes

- Returning from Analysis restores the Players workspace: chat answers and their public game links, draft, expanded chat, voice preference and chat scroll position; opening search query, colour, results/briefing and expanded continuation groups; existing board/search session state is preserved. Restoring does not call a model or replay audio automatically.
- Session snapshots are scoped to the authenticated account, bounded to 1 MiB per slot and cleared by the existing sign-out handler. A session revision prevents queued effects from writing old data after logout. Only the latest chat position/side/language context is retained. They last in this browser tab's session, not as cross-device or permanent memory. No tokens, keys, audio blobs or microphone recordings are serialized. Corrupt/unavailable storage degrades to an empty workspace.
- The visible “Your colour” selector is shared with the chat request; a Black learner is no longer sent as the unrelated position-search filter (previously `any`). Archive search filters retain their existing semantics. Browser checks cover Black/White requests with White to move, and colour restoration after analysis.
- Keys use account identity rather than a rotating access token. Preparation result keys omit tokens; in-flight operations still cancel on credential/query changes. Chat requests, audio and recording are cancelled/released on unmount/context change.
- Read-aloud expands canonical SAN into spoken piece names and file/rank words in DE/EN/AZ/TR/UK/RU (legacy UA accepted). It handles castling, captures, promotion, source disambiguation, check/mate, move numbers and coordinate moves. Displayed SAN/PGN is unchanged. This is syntax expansion, not a legality or engine-quality claim. The existing server-only Realtime model, voice, limits and authentication are unchanged.
- Coach context now includes board pieces, legal move source/target/capture/promotion details and check/terminal status from chess.js. Teaching instructions distinguish the learner's side from the side to move, require concrete plans and opponent resources, exact root SAN, and explicit separation of archive observations and unverified candidate analysis. No backend Stockfish calculation has been added; super-grandmaster accuracy is not established by these changes.
