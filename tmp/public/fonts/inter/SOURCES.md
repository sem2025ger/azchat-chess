# Inter

Inter 5.3.0 is bundled by Vite from the exact `@fontsource/inter` package pinned in `tmp/package-lock.json`.

- Upstream font: https://github.com/rsms/inter
- Distribution: https://fontsource.org/fonts/inter
- License: SIL Open Font License 1.1, included as `OFL.txt`.
- Existing normal weights 300–900 and all upstream language subsets remain available; the browser downloads only the subsets it uses.
- Font files and styles are served from the same origin as the app on desktop and mobile. No Google Fonts connection is required.
