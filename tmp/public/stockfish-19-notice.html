Corresponding source and build instructions

  • Download the release source archive (free access, no account required).
  • Browse the exact release source (commit 0d5dd7944f88c817c07a26bc4fb1905d5f9c46d6).
  • Build instructions: Emscripten 6.0.9, Node.js, upstream dependencies, then npm run build-single-lite. The upstream build script obtains and verifies the required neural network.
